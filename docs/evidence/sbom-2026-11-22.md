# 一次 SBOM

日期：2026-11-22。这不是试用，也不是 AC-01。

`requirements.txt` 有 23 行 `==` 锁定，直接依赖和已经锁住的传递依赖都在这份清单里。CI 的 check 作业另建一个虚拟环境，只安装这份清单，再 `pip freeze`。冻结结果必须和清单逐行相同。`cyclonedx-bom` 装在旁边的虚拟环境里，不写入 `requirements.txt`。扫描对象是前面那个只装了清单的环境。

命令是 `cyclonedx-py environment`，`--spec-version 1.6`，`--output-format JSON`，`--output-reproducible`，`--no-validate`。没有 schema 门禁。产物 `bom.json` 由 `actions/upload-artifact@v7` 上传，保留 90 天。

本页的包和许可证来自同一命令在本机的一次运行。解释器是 conda 环境 `k12-qbank` 的 Python 3.12，用来创建临时虚拟环境。格式是 CycloneDX JSON，`specVersion` 为 1.6。组件 24 个：清单里的 23 个，加上虚拟环境自带的 pip 25.0.1（MIT）。pip 不在清单里。CI 运行器上的 pip 版本可以不同，23 个锁定包的名字和版本应当相同。
