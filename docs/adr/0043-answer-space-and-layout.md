# ADR 0043 答题区大小与按高度排版

状态：accepted

## 背景

R4b 把每页分成 4 个等高槽位。选择题只写一个字母，解答题要写几步，两种题用同一个约 2.5 cm 的框。题干或选项越过答题框时，行被丢掉，出卷仍成功。页眉和二维码的位置、大小写在排版函数里，打印之后不能改参数。

答题区要多大，取决于这道题怎么答，不取决于老师这次出给谁。已经发出的卷不能因为后来改了参数而挪框。收卷裁切要读出卷时记下的坐标。

## 选项

1. 继续按槽位编号推坐标。老师出卷时手调框的高度。
2. 答题区大小属于题目。导入时按题型给默认值，书清单可以逐题覆盖。出卷按高度往下排，把每个框的坐标写入卷记录。旧的槽位卷不重排。

## 决定

选 2。

- `answer_space` 只有 `letter`、`blanks`、`small`、`medium`、`large`、`full`。
- 默认：`single_choice` 与 `multiple_choice` 是 `letter`；`fill_blank` 是 `blanks`；`solution` 与 `composite` 是 `large`；`unresolved` 以及其他题型是 `medium`。
- 库里的 `approvals.answer_space` 为空表示用题型默认。排版时再算。不回填已有行。快照和目录接口返回算出来的值，并标明是不是默认。
- 书清单 `import-book.json` 可以带 `answer_space`。`key` 是核对页原键，`page` 是题目页页码，服务端按 ADR 0042 换成带命名空间的键。指不到题是 `no_question`，取值不在列表里是 `invalid_answer_space`，同一道题写两次是 `duplicate_answer_space`。三种都整本拒绝、零写入。
- `answer_space` 不是题目内容。重导时只有它变了，只更新这一列，结果是 `space_changed`，不是 `conflict`。省略覆盖会把已有覆盖清回空，也记 `space_changed`。题干等内容不同仍是 `conflict`，整本不写，答题区也不改。
- 填空题的空是题干里连续两个及以上下划线。空数是这些下划线串的个数。一处都没有时仍排一个小框。括号空不另计。
- 新卷 `layout_kind` 是 `flow`。`slots_per_page` 仍写 1，避免再走槽位打包。每道题的高度是题号、题干、选项的行数乘行高，加上答题区高度和题间距。这一页剩下的高度不够就换页。一道题占满一整页正文区还放不下，整份拒绝，错误码 `item_too_long`，报告写出题序和 `question_version_id`。不丢掉任何一行。
- `letter` 框在题号所在行的右侧，不另占一条答题带。`blanks` 按空数排成一行或几行小框。`small`、`medium`、`large` 是通栏，高度来自版式参数。`full` 在题干之下占到正文区底边。判断这一页还够不够放一道 `full`，用题干高度、题间距和 `large` 的高度；框本身下面不再留间距。
- 坐标计算是纯函数。输入只有题目列表和当时的版式参数。同样的输入得到同样的坐标。
- 每个框写入 `practice_item_box`：卷号、题序、框序、页码、x、y、宽、高（PDF 点）、框的种类。读卷和渲染只读这些行，以及出卷时抄下的题干行和页眉、二维码、定位标记。
- 版式参数是 practice 里的一份 JSON。`K12_PAPER_LAYOUT_PATH` 可以指向另一份。下限见 `docs/ops/paper-layout.md`。production 在启动时拒绝不合法的文件。development 在出卷时返回 `layout_invalid`，说明写出字段名。每份新卷在 `papers.layout_params` 存当时的页眉、二维码和定位标记。以后改参数文件，不移动已发出的卷。
- 页眉在左上角，内容是印在卷面上的学号，加「第 n 页 / 共 m 页」。不印姓名、班级、内部 `student_id`。二维码在右上角，默认模块 1.8 pt，四周静区 4 个模块，不和页眉重叠。`K12_PAPER_QR=off` 时不印。

## 后果

R4b 的等高槽位只用于已经发出的卷。`slots_per_page` 为 1 或 4 的卷仍走原来的排版，页面内容不变。新卷不再从槽位编号推答题框。

老师出卷时不改答题区。现在要改某一题的大小，只能在书清单里写覆盖后重导。核准页上修改留到后面的议题。

R5 收卷裁切只读 `practice_item_box`。公式排版不在本决定里。

## 状态

采纳。2026-11-24。
