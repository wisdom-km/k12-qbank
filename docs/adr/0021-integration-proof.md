# ADR 0021 真实阶段前要有一次集成验证

状态：accepted

## 背景

合成闭环只跑内存适配器。ADR 0012 把关系数据库定为 PostgreSQL，并且第一次写入要带可回退的迁移。ADR 0019 决定不做 SQLite，持久适配器保持「无」，直到那一次写入。

文件存储现在是 `MemoryFiles`，字节只在进程内存里。老师登录现在是 `MemoryAuth`。都不是真实阶段要用的适配器。

真实阶段开始之前，这三件要有一次放在一起证明，而不是各写各的。

## 选项

1. 现在就连接 PostgreSQL，建表，接上文件存储和真实老师登录，把 AC-01、AC-02、AC-04 跑一遍。
2. 现在只记下这次验证必须一起发生。不连接，不建表，不选驱动，不实现登录。

## 决定

选 2。真实阶段开始前，至少一次同时跑这三件：

- 会写行的 PostgreSQL 适配器
- 会把文件存下去的文件存储适配器
- 真实老师登录

这一次要走完 AC-01、AC-02、AC-04。缺任何一件，那次不算集成验证。

第一次写入仍按 ADR 0012：同一改动里要有可回退的迁移，并且只建这次有行要写的表。不改 ADR 0012，不改 ADR 0019。

这一改动不连接数据库，不建表，不新增驱动，不写登录。驱动仍未选定。

## 后果

实现矩阵里的持久适配器保持「无」。合成数据上的 M1 不被这条挡住。没有这三件同时在场的证据之前，不把真实阶段说成已经开始。

## 状态

采纳。2026-11-18。用户要求按建议先记下集成验证。不连接 PostgreSQL。
