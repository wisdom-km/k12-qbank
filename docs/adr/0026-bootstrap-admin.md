# ADR 0026 首个管理员

状态：accepted

## 背景

库里没有任何管理员时，没有人能创建老师。不能把初始口令写进仓库，也不能写进日志。

## 选项

1. 仓库里放一个默认管理员口令。
2. 进程启动时读 `K12_BOOTSTRAP_ADMIN_USERNAME` 和 `K12_BOOTSTRAP_ADMIN_PASSWORD`。仅当用户表里没有 `admin` 时创建一次。
3. 做密码找回邮件。

## 决定

选 2。

- 两个变量都非空、且库里没有 `admin` 时，创建一名活跃管理员。
- 已有管理员时，这两个变量不再生效。
- 口令只用于这一次哈希。不写入运行日志、审计日志或错误上报。
- 创建成功后，操作者应清空这两个环境变量。进程不会把它们写回文件。
- 不做密码找回邮件。

## 后果

本地和部署都通过环境注入首个管理员。`.env.example` 里这两个值留空，并注明首启后清空。

## 状态

采纳。2026-11-18。
