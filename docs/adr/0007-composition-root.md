# ADR 0007 只有一个装配根

## 背景

数据库、文件、时钟和模型都要能在测试里换成假的。若每个入口自己 new 具体类，规则会分叉。

## 选项

1. 网页、安卓后端路由和后台任务各自创建依赖。
2. 一个组合根按配置创建具体对象并注入用例。入口文件只装配，不写业务分支。

## 决定

选 2。组合根的位置定为 `backend/bootstrap/compose.py`。这个文件在第一条用例落地时再创建。在此之前仓库里没有装配根，也不要在别的文件里提前 new 供应商客户端。

网页、安卓 API 和后台任务调用同一组用例。

## 后果

配置集中。组合根会变长；变长时按切片拆装配函数，不把业务判断搬进去。这条「入口不写业务分支」目前靠 review，脚本查不到。

## 状态

采纳。2026-11-14。
