# ADR 0005 分析用三个端口

## 背景

识别题目、分析手写、推荐下一题都会调用外部模型，但失败的含义不同。识别失败不是学生做错。推荐只能看老师已经确认的记录。

## 选项

1. 一个 AI 端口，里面包含识别、解题、批改和推荐。
2. 三个端口：题目草稿、作答分析、练习推荐。每个端口可以有真实适配器和内存假适配器。

## 决定

选 2。端口由用例定义，名字用业务能力，不用供应商名字。

作答分析的失败必须是可区分的结果：超时、服务不可用、格式不合法、看不清。这些结果不能写成「学生答错」。

换供应商时，先改适配器、配置、映射和契约测试。R1 到 R6 不因换供应商而放宽。同一套契约测试要跑在假适配器和真实适配器上。接口相同不表示识别质量、时延或费用相同。

评审工具的分数不是本项目测过的正确率，不能因为分高就跳过老师核验。

## 后果

供应商适配器变多，用例更稳。假适配器只能用于开发和 core 测试。验收 AC-04 和 AC-09 必须用经机构允许的真实样本，并单独记录人工处理次数。

## 状态

采纳。2026-11-14。具体供应商仍未选，见 ADR 0010。
