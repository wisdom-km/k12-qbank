# ADR 0009 关系数据和文件分开

## 背景

原 PDF、页图、裁图、参考答案、作业照片和导出的 PDF 都很大，而且要按校验值追溯。学生、题目、卷次和审核之间要有约束和事务。

## 选项

1. 把文件路径写死在本机目录，所有内容再塞进一个大 JSON。
2. 关系数据放数据库；文件放受控存储；数据库只记录稳定标识、用途、校验值和关联。题目正文用结构化 JSON 加独立字段，JSON 不是唯一的库。

## 决定

选 2。文件和数据库没有同一个事务。顺序是：先把文件放稳并核对成功，再登记引用。失败时留下可恢复状态，无引用的临时文件延迟清理。删除前先核对引用和保留规则。

中文检索首版用标签、来源、章节、题型、难度和简单文本匹配。不在第一天引入向量库。公式保存可编辑的 LaTeX 候选，并保留原图。图形先是图片。

数据库产品见 ADR 0010，仍是提议。关系数据和文件分开这一点先采纳。

## 后果

备份必须同时包含数据库和文件。只拷一种，恢复演练不算通过。迁移文件在第一条持久化落地时加入，并要能回退。

## 状态

采纳（存储分工）。数据库产品未采纳。2026-11-14。
