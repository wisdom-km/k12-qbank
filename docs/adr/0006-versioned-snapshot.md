# ADR 0006 发卷时冻结版本

## 背景

题库会改正。已经发出的学生卷必须还能对上当时的题目、答案和版面。题目核验和答案核验是两件事。

## 选项

1. 题目表上一个状态字段，改题就覆盖。旧卷读当前行。
2. 题目版本、答案版本和发布记录分开。学生卷保存当时的发布标识、题序和版面。以后改题产生新版本，不改旧卷。

## 决定

选 2。只有题目版本和适用的答案版本都已核准，才能组成可正式出卷的发布记录。未核准或有争议，正式出卷和自动评分拒绝。

已经发出的历史例外只能人工评分并留痕，不提供平时绕过核验的入口。

发现已发布内容有错：停止用于新出卷，标出受影响的旧卷，由老师按新版本做带原因的更正。

## 后果

存储比覆盖更新多。历史可回放。实现时要有测试：建卷后改题，旧卷快照不变。

## 状态

采纳。2026-11-14。
