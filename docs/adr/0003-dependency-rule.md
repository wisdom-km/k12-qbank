# ADR 0003 依赖只能向内

## 背景

网页、安卓、数据库和模型供应商都会换。业务规则不能跟着它们的类型一起换。

## 选项

1. 界面直接调用数据库和模型 SDK，规则写在点击处理里。
2. 界面只调用用例；用例只依赖本切片领域和端口；具体数据库、文件和模型由组合根注入。

## 决定

选 2。源码依赖方向：

界面和任务入口 → 用例 → 领域规则，以及端口。

适配器实现端口，由组合根装配。领域和应用不出现框架、ORM、供应商 SDK 的名字。跨切片只导入对方的 `api` 模块。领域只导入 kernel 和本切片的领域包。

## 后果

core 测试可以不启动网页、不连数据库、不调用模型。检查脚本会拒绝违规 import。组合根里若写业务分支，当前脚本查不到，靠 review。

## 状态

采纳。2026-11-14。
