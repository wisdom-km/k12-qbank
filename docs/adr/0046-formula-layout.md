# ADR 0046 卷面公式按排版印出

状态：accepted

## 背景

issue #94：卷面把公式按 LaTeX 源码原样印出。学生看到的是 `\frac{1}{2}` 这种源码，没法对着卷子作答。

边界丢了两次。题目草稿里文字片段和公式片段是分开的。`stage_review._plain` 把它们拼成一整串纯文本，写进 `approvals.stem`。出卷再把这串抄进 `practice_item.stem_text`。渲染器只认识普通文字，不认识公式。

ADR 0043 按行数乘行高计算题目高度。一行里有分数时，行高必须按这一行里最高的那一块算，否则下一题会叠上来。

## 选项

1. 引入 TeX 引擎或 KaTeX，在服务端把公式画成图再贴进 PDF。
2. 出卷时从纯文本里猜哪里是公式，再排版。
3. 新导入的题从草稿起分开保存文字和公式。排版是 practice 里的纯函数，只用现有渲染器画字形和分数线。不认识的命令不印源码。旧行和已发出的卷不改写。

## 决定

选 3。

### 公式边界

草稿里的 `TextPart` 和 `MathPart` 在核准时仍按原来的方式拼成 `approvals.stem` 和选项纯文本。整书导入的 kept / conflict 只比较这些纯文本、答案纯文本和题型，不比较片段。

同一条迁移 V016 给 `approvals` 增加可空的 `stem_parts`、`option_parts`，给 `practice_item` 增加这两列，再加可空的 `formula_draw`。不回填旧行。新导入的题写入片段：`[{"type":"text","value":"..."},{"type":"math","latex":"..."}]`。选项片段按选项键对齐。`NULL` 表示这份快照没有结构化片段。空数组表示结构化过、里面没有片段。不从纯文本里猜公式。

已导入且比较结果是 kept 的行不再写入。重导不会给旧行补上片段。要得到结构化片段，在核对页改成支持的写法后，作为新版本再导。

老师在核准页修订题干时，新版本的片段清空。修订送来的是纯文本，不沿用旧片段，也不从纯文本里拆公式。题干和答案都没变时，原版本保持原样。

出卷把片段和排好的字形、分数线冻进 `practice_item`。`formula_draw` 里是字形 `(g, 文字, x, y, 字号, 字体, 纵向缩放)` 和线段 `(r, x1, y1, x2, y2)`。再打开这份卷时只画这些坐标，不重新排版。

`questions.stem` 仍是草稿形状。新核准写入题目行时，有片段就按片段写；没有片段的旧路径仍写一整段文字。不更新已经存在的题目行。

### 支持的写法

排版函数在 `backend/practice/domain/formula.py`。输入是一个公式片段和字号。输出是字形、线段、宽、高和基线。不读字体文件。

- 数字、拉丁字母、括号、正负号、小数点、逗号
- 运算符 `+ − × ÷ ± · = ≠ ≈ < > ≤ ≥`，命令 `\times` `\div` `\pm` `\cdot` `\neq` `\approx` `\leq` `\geq` `\le` `\ge`
- `\frac`、`\dfrac`、`\tfrac`：分子在分数线上方，分母在下方。可以嵌套。带分数是整数紧挨一个分数
- `^{...}`、`^x`、`_{...}`：字号按 0.7 缩小，上标上移，下标下移。上下标挂在前一个原子上
- `|x|`、`\left| \right|`：竖线按内容高度画。`\left(` `\right)`、`\left[` `\right]`：括号按内容高度拉高
- `\angle`、`\circ`、`\prime`、`\pi`、`\%`
- `\text{...}`、`\mathrm{...}`：里面可以有中文
- `\,`、`\;`、`\quad`、`~`、反斜杠加空格

`\frac`、`\dfrac`、`\tfrac` 用同一种上下排，不另改字号。折行不把一个公式拆开。公式比整行还宽时，整份卷拒绝。

数字和字母用拉丁字体。运算符和中文用部署环境的中文字体。缺字形仍是 `not_rendered`，不用方块代替。

字号、上标比例和分数线间距是代码里的固定比例，不是 `paper_layout.json` 的字段。数值见 `docs/ops/paper-layout.md`。流式排版的正文字号仍用那份 JSON 的 `font_size`。

### 不支持的命令

导入时：整书报告给这道题记警告，原因是 `formula_unsupported` 加命令名。导入结果仍是 staged、kept、skipped 或 space_changed。不挡导入。

出卷时：这道题让整份拒绝。`formula_unsupported` 写明题目版本和命令名。`formula_unstructured` 用于旧行：片段是空，纯文本里又有反斜杠命令。`formula_too_wide` 用于一个公式比一行宽。三个都是 HTTP 409。日志只记错误码，不记公式源码。卷面任何情况下都不印源码。

### 为什么不引入 TeX 或 KaTeX

排版只服务七年级上册这一段要用的写法，输入和输出都是仓库里的普通数据。TeX 引擎或 KaTeX 会新增依赖，也会把版面交给另一套程序。缺字、过宽和不认识的命令要在出卷时变成稳定错误码，而不是一张图片或一串源码。

### 旧题和旧卷

片段为空的旧题照旧按纯文本印。目录接口的 `formula_note` 写「公式未结构化」。纯文本里没有反斜杠命令的，出卷行为与这一批之前相同。

已经发出的卷用存下来的 `placed_lines`、`practice_item_box` 和 `paper_pages.formula`。没有 `formula_draw` 的卷不重新排版，也不在打开时删掉当时印下的文字。

## 后果

根号和方程组的大括号不在这一批。它们出卷会被拒绝，不印源码。识别率仍是 R6a，采用建议的界面仍是 R7。

## 状态

采纳。2026-11-24。

## 修订（2026-11-25，R4f）

支持清单增加 `\textcircled{1}` 到 `\textcircled{20}`。排版成 ①（U+2460）到 ⑳（U+2473）。数字不在 1 到 20，或括号里不是数字，排版报 `formula_unsupported`，命令名是 `\textcircled`。缺字形仍是 `not_rendered`，不用方块代替。本机常见的微软雅黑和宋体有 ① 到 ⑩，没有 ⑪ 到 ⑳。要印后面这些，把 `K12_PDF_FONT_PATH` 指到含 U+246A 到 U+2473 的字体。字体文件不进仓库。上文的支持清单是当时的决定，不删。
