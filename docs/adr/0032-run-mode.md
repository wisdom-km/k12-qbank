# ADR 0032 运行模式

状态：accepted

## 背景

ADR 0028 规定 `K12_PG_DSN` 为空时用内存，有值时连接。真实老师的进程不能在没库时静默改用内存。本机合成和单测仍要能不连库。不改 ADR 0028 的正文。

## 选项

1. 任何进程都要求连接串。单测也要数据库。
2. 增加 `K12_ENV`，只接受 `development` 和 `production`。默认 `development`。

## 决定

选 2。组合根按下面四行选择，不新增依赖。

- 未设置或空字符串是 `development`。除此之外的值：标准输出一条 ERROR，进程以退出码 1 结束。
- `production` 且连接串为空：标准输出一条 ERROR，退出码 1。
- `production` 且连接串有值：连接并迁移。
- `development` 且连接串为空：不连接，标准输出一条 WARN。单测走这一行。
- `development` 且连接串有值：连接并迁移。

这四条日志都不写连接串，也不写口令。

## 后果

ADR 0028 的「连接串为空则用内存」只在 `development` 成立。`production` 不允许这条回落。默认值仍是 `development`，所以现有不设连接串的合成命令行为不变，只是多一条 WARN。

## 状态

采纳。2026-11-18。不改 ADR 0028 正文。
