# ADR 0020 学情保留和删除

状态：accepted

## 背景

真实学情会进入系统。现在仓库里没有正式数据，也没有开发库。

这里说的学情，是一名学生的三类记录：照片、作答记录、建议。题目、参考答案、发布记录，以及其他学生的卷，不是这名学生的学情。

ADR 0008 已经把日志保留多久留给 DEC-03。那条正文不改。QM-04 的备份窗口也仍是待定标。DEC-01 到 DEC-06 仍不代填。

## 选项

1. 现在写死保留天数，并实现删除。
2. 不写天数。先记下删除必须覆盖这三类，而且删除前要人确认、先有备份。天数仍等 DEC-03。这一改动不实现删除。

## 决定

选 2。不发明保留天数。

机构可以要求删掉一名学生的照片、作答记录和建议。删除前要人确认，并且先有备份。删除之后，工作数据里不再有这三类。题目、参考答案、发布记录和其他学生的卷仍留着。

备份保留多久、谁可以看日志，仍等 DEC-03。不改 ADR 0008 的正文。不填 DEC-01 到 DEC-06。

这一改动不连接数据库，不建表，不写删除代码。合成数据上的 M1 闭环不被这条挡住。真实学生试用前，AC-10 仍要能观察到。

## 后果

PRD 增加 US-12 和 AC-10。AC-10 不写天数。实现矩阵不改，因为没有新适配器。

## 状态

采纳。2026-11-18。用户要求按建议记下学情怎么留、怎么删。不写天数。不取代 ADR 0008。
