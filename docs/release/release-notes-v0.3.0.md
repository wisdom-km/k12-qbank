# 0.3.0

日期：2026-11-23。标签打在本说明合入 main 之后的提交上。`v0.2.0` 仍在 `925bc36`。

本版 **非对外发布**。G3 仍因 #47 未通过而不可对外开放教学服务。本版用于内部迭代节点存档。

## 这一版多了什么

相对 0.2.0，库里可以放下题目、答案、一道卷上的多道题，以及一条发布记录。管理员可以发布、作废、看发布列表，并给一条发布挂上或卸下资产记录。资产记录保存的是元数据。文件字节的存放方式还没有选定。

安全基础八条有了书面状态。第 5 条没有费用上限。草稿库和两份文件做过一次一起恢复，用时写在演练记录里。

依赖有固定版本。持续集成会做依赖扫描，并留下一份软件物料清单。生产环境必须写明允许的网页来源。名单空着，或写成星号，进程不会启动。

认证、跨源、请求体上限、速率、依赖扫描和物料清单的现状都有证据页。请求体上限只看带长度头的请求。速率只限登录和就绪检查。这些页不代替验收签字。

## 升级

已经在用 v0.2.0 数据库的，先备份，再把迁移升到 V009。那个标签上只有 V001。其后补上的是 V002 到 V009，包括题目与答案、子表、练习项、发布、资产，以及第二次 retire 用的部分唯一索引。

升完再启动进程。已经有两条 retired 的库不要对 V009 做 down。

网页包版本从 0.1.0 改为 0.3.0。Python 依赖仍以 `requirements.txt` 为准，其中 fastapi 0.165.0、starlette 1.10.0。

回滚应用代码用反向提交，经 PR 合入。不移动 `v0.2.0`，也不删除 `v0.3.0`。

## 已知限制

外部错误上报还没有接收方。#47 仍打开，所以这一版不能当对外教学服务。

仍在本仓之外：HTTPS、备份加密、密钥轮换、DEC-01 到 DEC-06、`D:\ui` 的界面原型、附件字节上传。

留到以后：没有长度头时的正文拦截、登录和就绪以外的次数限制、#73 的 httpx2 警告、发布列表按数字序。

正式库的位置还没有。备份不加密。保留天数未定。
