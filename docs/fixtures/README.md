# 合成夹具

本地开发和 core 测试只用合成数据。这里的标识都是编出来的。不要放入真实学生的姓名、学号、照片或答卷。

## 最小结构

一份夹具有五块：

| 块 | 内容 |
| --- | --- |
| question | 题目版本标识、学科、题干、是否已核准 |
| answer | 答案版本标识、答案文本、是否已核准 |
| student | 合成学生标识。卷面不印姓名，所以没有姓名 |
| paper | 一次发给该学生的卷。题目版本和答案版本是发卷时要冻结的标识 |
| photo_version | 照片版本。这一段只有页标识和版本号，没有图片字节 |

## 示例

[rational-number-min.json](rational-number-min.json) 是一道有理数运算的最小夹具。标识与 core 测试里的合成数据一致：`q-v1`、`a-v1`、`student-synth`、`teacher-synth`。

再做一份时，复制这个文件，只改合成标识，五块都保留。不要粘贴真实照片的 base64，也不要填真实姓名。

这份文件不启动服务，也不写入数据库。出卷用例冻结的是题目版本和答案版本；测试里的内存快照可以沿用同一组标识。
