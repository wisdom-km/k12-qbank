# 机构试用操作录屏分镜

给 Wisdom 录 5–8 分钟机构使用视频。本页只是分镜和验收点。视频由人来录，本页不表示已经录完。

五幕按顺序来。每一幕先说画面上要点哪个按钮，再说预期出现的字。口播可以按自己的话讲，不要念出口令。

## 录屏避坑

- 不要让 `.env.trial`、终端里的 `K12_PG_DSN`、数据库口令、`K12_BACKUP_PASSPHRASE` 或 API key 进入画面。
- 不要让真实学生姓名、学号或整页手写照片进入画面。样张实测另做，不放进这条给机构的片子。
- 口令框保持为密码点。老师编号、学生编号如果是内部标识，可以一闪而过，不要特写。
- 录之前把桌面上的真实书目录和终端历史关掉。

## 第 1 幕：管理员建号、授权、拖拽导书

约 1.5 分钟。用已经改过口令的管理员。如果这是首启，先打开 `/account`。

1. 打开 `/login`。标题是「登录」。填写用户名和口令，点「登录」。
2. 首启时打开 `/account`。标题是「修改我的口令」。填写原口令、新口令，点「保存口令」。页面出现「口令已更新」。改密前如果去点「创建老师」，页面出现 `password_change_required`。改密后再继续。
3. 打开 `/admin`。标题是「管理」。
4. 在「老师」里填写用户名和口令，点「创建老师」。上方出现一行 `request_id`。名单里出现这名老师。
5. 在「学生」里填写学号、年级、学科。姓名可以空着。点「创建学生」。名单里出现这名学生。
6. 把老师编号和学生编号填进「授权」，学科填 `math`，点「授权」。列表里这一行是「有效」。
7. 把核对页导出的书文件夹拖进页面，或点选择文件夹。先点「预演导入」。状态是「预演未写入」。没有拦截后再点「确认写入」。状态是「已写入」。

## 第 2 幕：老师按课时核准并出卷

约 1.5 分钟。退出后用老师账号登录。

1. 老师页标题是「有理数出卷」。
2. 打开一个课时，点「选中本课时全部可出卷的题」，或逐题打开。未核验的题点「核准并发布」。页面出现「已核准并发布」。课时旁的可出卷题数增加。
3. 在「出卷」里选这名学生，点「出卷」。页面出现卷号、状态和「打开 PDF」。
4. 点「正式发放」。状态变成「已发放」。

## 第 3 幕：拍照收卷与 AI 识别

约 1.5 分钟。手机和电脑在同一网络。不要拍真实学生卷。

1. 老师页「收卷」写着「拍照或从相册选。读不出二维码时，从自己出过的卷里选一页。」
2. 手机打开老师页，点「拍照」或「从相册选」。二维码读出后，该页显示已收。
3. 读不出码时，在「选择页」里选「第 1 页」再上传。
4. 该页下方点「AI 识别」。等待结束。不要切到真实模型。默认 mock 即可演示按钮位置。正式样张另按 [ai-accuracy.md](ai-accuracy.md) 做。

## 第 4 幕：批改确认，再出一份练习

约 1.5 分钟。

1. 在「缺页」那一列点「批改」，或直接打开 `/papers/<卷号>/grade`。标题是「批改」。说明文字是「AI 建议只有经老师采用或改判后才算结果」。
2. 至少一题点「采用」。该题出现「老师结论」。
3. 至少一题点「改判」，结论选「错」，点「保存改判」。
4. 下方「再出一份练习」里勾上已确认的错题，点「再出一份练习」。页面出现「新卷号」。可再点「正式发放」。

## 第 5 幕：识别率对账与备份提醒

约 1 分钟。换回管理员。

1. 打开 `/admin`，找到「识别率对账」。点「刷新对账」。页面有已批改和关联 AI 的计数。没有记录时显示「暂无已完成对账的 AI 识别记录」，这不是故障。
2. 口播提醒：每个工作日做一次加密联合备份，并做 `--verify-only`；满 30 天的收卷照片用加密归档。不要在画面里打开终端口令，不要执行 `docker compose down -v`，不要动本机库 `k12`。
3. 口播收束：正式证书、规模化备份、外部错误上报、真卷版式、真实样张阈值、按课时自动配对和多名学生出卷，仍由人跟进，不在这条片子里宣称已经完成。

## 验收

- 成片 5–8 分钟，五幕都在。
- 能看见「预演未写入」「已写入」「已核准并发布」「已发放」「批改」「再出一份练习」「识别率对账」。
- 画面里没有 `.env.trial`、API key、数据库口令或真实学生姓名。
