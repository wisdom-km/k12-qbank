# 收卷

老师在自己的页面上收整页照片。一张卷的一页同时只有一条未作废的收卷记录。照片 purpose 是 `intake`，和出卷 PDF 的 `page` 分开。

只有这张卷的出卷老师和管理员能看收卷状态和照片。每次成功读取写一条审计 `intake_read`。审计不写学号，也不写图片内容。

## 老师怎么收卷

登录后打开首页。收卷区有两个入口。

- 「拍照」打开后置摄像头，一次一张。
- 「从相册选」可以多选。

每张照片在浏览器里摆正、把长边缩到不超过 3000 像素，再用 jsQR 读二维码，然后重新编码成 JPEG。这一步去掉 GPS 和其他拍摄信息。

读出码，并且这张卷在你出过的列表里：这一行显示「学号 ×××，第 n / m 页」，然后上传。学号来自已经授权的出卷记录，页面上不显示内部 `student_id`。

读不出码，或这张卷出卷时没有印码：这一行标「未识别」。从自己出过的卷里选一张，再选页码。卷按出卷日期分组，每一行是学号和日期。没有记下日期的归在「未记下日期」。

照片一张一张上传。每一行显示结果。

这一页已经收过时，服务端返回 `page_already_received`。页面问「替换吗」。确认后带 `replace=true` 再传。旧记录记下作废时间。旧照片留到下面的到期归档，替换当时不删除。

## 怎么看缺页

每一张卷有一行进度：已收几页 / 共几页。缺页时写明缺第几页。刷新页面后仍按服务端的收卷状态显示。

## 手机连本机

手机和电脑连同一个 Wi-Fi。不要用手机流量。

查电脑的局域网地址：在电脑上打开 PowerShell，执行 `ipconfig`。看当前 Wi-Fi 适配器的 IPv4 地址，形如 `192.168.x.x`。不要用 `127.0.0.1`，那只在电脑自己能打开。

启动时带上这个地址。在仓库目录执行：

```text
$env:K12_HTTP_HOST = "192.168.x.x"
python -m uvicorn backend.bootstrap.http_app:app --host $env:K12_HTTP_HOST --port 8765 --no-access-log
```

`K12_HTTP_HOST` 默认是 `127.0.0.1`。`scripts/check.conf` 不读这个变量，检查脚本仍只绑本机。想让局域网里的手机连上，启动命令的 `--host` 要写成上面的地址，或写成 `0.0.0.0`。写成 `0.0.0.0` 时，手机仍用电脑的局域网地址访问，不要在手机里输入 `0.0.0.0`。

手机浏览器打开 `http://192.168.x.x:8765/login`。把 `192.168.x.x` 换成上一步看到的地址。老师登录后在首页使用「收卷」。

风险：这段局域网连接是 http，口令不加密传输，只用于自测。正式试用用 R9 的 HTTPS。

## 保留

收卷照片在下面两种情况满 `K12_INTAKE_RETENTION_DAYS` 天后归档。这个值未设或不是正整数时按 30 天。

- 整张卷的题目都已由老师确认，并且最晚一条未作废结论已满 N 天。
- 被替换的旧照片，作废时间已满 N 天。

未批完的卷不归档，哪怕照片上传已超过 N 天。出卷 PDF（`files.purpose` 为 `page`）不归档。老师结论、识别建议和出卷记录都不删。

归档命令是 `scripts/archive_intake.py`，不走 `scripts/retention_sweep.py`。先加密打包并核对 SHA-256，通过后才标记 `archived_at` 并删除在线照片字节。没有口令时不写、不删。库名是 `k12` 时拒绝执行。步骤见 [trial-deploy.md](trial-deploy.md) 第 9 节。

已归档的照片再打开，或再点「AI 识别」，返回 410 `intake_archived`。批改页上已经确认的结论和历史建议仍可看。
