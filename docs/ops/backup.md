# 备份

开发数据和正式数据分开。正式库的位置还没有。agent 只使用本机开发夹具，不连接正式库。

删除真实学生数据前要人确认。能标记作废就不要物理删除。

现在没有数据库，所以没有 `pg_dump`。文件备份的演练命令是：

```text
python scripts/drill_backup.py
```

它只造一份临时夹具，复制备份，再恢复到另一个临时目录并核对校验值，然后删掉夹具。这不是正式学情的备份。数据库选定并有了第一份持久化数据之后，同一次演练必须同时包含数据库转储和文件，缺一不可。

备份放在本机 `var/backups/`（已被忽略，不进仓库）。保留多久等机构确认，数字仍待定标。
